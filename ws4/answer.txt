sedit()

This function edits files with administrator privileges. It uses if/elif conditions to check whether jpico, nano, or pico is installed by using the `type -t` command. It opens the file with the first available editor using `sudo`. If none of those editors are available, it falls back to `sudo vim`.

extract()

This function extracts archive files. It first checks whether each argument is a valid file using `if [ -f $archive ]`. It then uses a `case` statement to determine the archive type and executes the appropriate command, such as `tar`, `gunzip`, `bunzip2`, `unzip`, or `7z`, to extract the file.
